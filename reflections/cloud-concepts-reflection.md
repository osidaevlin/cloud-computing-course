# Cloud Computing Concepts Reflection

Cloud computing has changed the way I study, communicate, and complete everyday tasks. Before taking this course, I simply used online applications without thinking about the technology behind them. After learning about cloud computing, I now understand that many of the services I depend on every day are powered by cloud infrastructure. This knowledge has helped me appreciate how cloud computing provides convenience, accessibility, and reliable access to information from almost anywhere.

## 1. Cloud Services I Use

Three cloud services that I frequently use are **Google Drive**, **Netflix**, and **Facebook Messenger**. These applications help me store school files, watch movies and TV shows, and communicate with my family, friends, and classmates.

## 2. Identify the Models

Google Drive is an example of **Software as a Service (SaaS)** because it provides online file storage and document management without requiring users to install or maintain servers. It uses the **Public Cloud** deployment model because anyone with a Google account can access the service.

Netflix is also a **Software as a Service (SaaS)** application because it delivers movies and television shows through the internet. It is classified under the **Public Cloud** since subscribers around the world access the same cloud-based streaming platform.

Facebook Messenger is another **Software as a Service (SaaS)** application because it allows users to send messages, make voice and video calls, and share files through an online platform. It also operates on the **Public Cloud**, making it available to millions of users worldwide.

## 3. Git & GitHub for Cloud Projects

Git and GitHub play an important role in managing cloud projects. Version control helps developers keep track of every change made to files, making it easier to fix mistakes and restore previous versions when necessary. GitHub allows multiple team members to work on the same project without overwriting each other's work. By using branches, pull requests, and commit history, teams can collaborate more effectively, review updates before merging them, and reduce the risk of errors. These features make cloud development more organized, efficient, and reliable.
